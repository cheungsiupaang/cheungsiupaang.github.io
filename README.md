# cheungsiupaang.github.io

Personal academic website for Zhaopeng Zhang, built with Jekyll and hosted on GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000>.

## Main content

- `_pages/about.md`: homepage sections
- `_includes/publications-list.html`: publication list shared by the homepage and `/publications/`
- `_pages/ringo.md` and `_pages/tmech.md`: project pages
- `_publications/`: publication images and styles
- `files/`: linked paper PDFs
- `CV/zzp-CV.pdf`: downloadable CV

Generated output belongs in `_site/` and is intentionally not tracked.
